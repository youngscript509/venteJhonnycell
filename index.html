🖨 Impression des reçus

Choisissez comment cet appareil imprime les reçus. Le Mode 2 permet à une tablette d'envoyer l'impression vers un Sunmi V2 distant, sans app supplémentaire.

Mode 1 : à utiliser si RawBT est installé sur CET appareil (typiquement sur le Sunmi V2 lui-même).
Mode 2 : à utiliser sur une tablette qui n'a pas RawBT — l'impression est envoyée au Sunmi V2 enregistré ci-dessous.

—
—

📟 Cet appareil est le Sunmi V2 imprimante

Activez ceci UNIQUEMENT sur le Sunmi V2 où RawBT est installé. L'appareil restera à l'écoute des commandes d'impression envoyées par les tablettes en Mode 2, et devra rester ouvert sur cette page.
